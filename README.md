# 💻 DevTech — Landing Page Responsiva

Landing page de uma empresa fictícia de tecnologia, feita como exercício prático avaliativo de desenvolvimento web no curso de Sistemas de Informação (UNEMAT).

## ✨ Seções

- **Header** com menu de navegação por âncoras
- **Hero** com chamada principal e botão de orçamento
- **Serviços**, **Portfólio** e **Contato**
- Layout **responsivo**, que se adapta a celular, tablet e desktop

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (Flexbox e media queries)

## 📁 Estrutura

```
AULA3/
├── index.html
├── css/Devtech.css
└── img/          # imagens do hero e dos serviços
```
